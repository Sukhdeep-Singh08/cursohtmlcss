Una metodologia es una forma especifica para trabajar. (BEM)

- Reutilizar Codigo / Optimizar codigo
- Se resuelven problemas de Especifidad
    · Como nombrar las clases,etc.

La metodologia BEM se divide en 3 partes:
* Bloque : Un componente que no depende de nadie para poder existir.Que se puede reutilizar.
* Elemento : Hace referencia de una parte de un bloque, que por si solo no tiene sentido pero dentro de un bloque si lo tiene.
* Modificación: Una forma de moficiar un elemento o un bloque.
