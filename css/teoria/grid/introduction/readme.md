    GRID es de dos direcciones no de una. Es decir filas y columnas.

    GRID CONTAINER = El elemento padre q se dispone como un contenedor cuadricula.
    GRID-ITEM = Los hijos directos del contenedor del GRID, pueden ocupar mas de una celda o mas.
    Lineas = Separan cada celda
    GRID-CELL = Es el espacio real del elemento
    GRID- AREA = Constar mas de una celda.
