Un servicio que da espacio donde almacenamos información.

Proveedores:
- Accessibilidad
- Almacenamiento
- Seguridad
- Soporte 24/7

Tipos de Hosting: 
- Hosting Compartido: Un servidor contiene muchos sitios webs.
- VPS (Virtual Private service) : Un servidor separa fisicamente el servidor en partes y q cada parte actuan como servidores diferentes. No se ve afectado el rendimiento en cada servidor.
- Hosting especializado: Un hosting adaptarlo para alguna app.

CDN = Aumenta velocidad de carga, disminuye la latencia y aumenta la disponibilidad y la seguridad.
